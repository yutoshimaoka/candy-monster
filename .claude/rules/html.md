## HTML ルール

- セクションごとに以下の区切りコメントを入れる：
  <!-- ============================================ -->
  <!-- セクションタイトル -->
  <!-- ============================================ -->
- `<meta name="viewport" content="width=device-width, initial-scale=1">` を必ず設定する
- セクションは `<section>`、ナビは `<nav>`、ボタンは `<button>` を使う（`div` で代用しない）
- 見出しは `h1` → `h2` → `h3` の順に使い、レベルを飛ばさない
- ハンバーガーメニュー・アコーディオンの矢印は SVG で出力する（PNG / `border` での代用不可）
- リンクは遷移先を必ず設定する：
  - `<a>` には適切な `href` を設定し、`#` や空・ダミーのまま放置しない
  - ページ内リンクは対応する要素の `id` を指す（例：`href="#features"`）
  - 遷移先が未定の場合は仮置きせず、TODO コメントを残して未設定であることを明示する（例：`<!-- TODO: リンク先未定 -->`）
  - 外部リンクは `target="_blank"` に加えて `rel="noopener noreferrer"` を付ける
  - 電話・メールは `tel:` / `mailto:` を使う
- CTA・ヘッダーナビ・フッターの各ボタン/リンクは、Figma やワイヤーで指定された遷移先と一致しているか確認する
