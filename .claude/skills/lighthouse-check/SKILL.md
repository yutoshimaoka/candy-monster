## Lighthouse 計測スキル（品質検証）

> このスキルは **実装後の品質計測と改善提案**が担当です。
> セクションの新規実装は担当外です（`lp-implementation` が担当）。

### このスキルを使うタイミング
- 全セクションの実装が完了し、公開前に品質を数値で確認したいとき
- 特定スコアが低く、改善したいとき

### 手順

**1. Lighthouse を実行する**
- パフォーマンス・アクセシビリティ・ベストプラクティス・SEO のスコアを計測する
- PC / モバイル両方で計測する

**2. 目標との差分を確認する**
- 目安：パフォーマンス 90以上／アクセシビリティ 95以上
- 下回った項目について、原因と改善案を具体的に挙げる

**3. 主要な観点をチェックする**
- パフォーマンス：画像最適化（WebP / srcset / lazy）、フォント読み込み、LCP/CLS/INP
- アクセシビリティ：コントラスト比、`aria` 属性、`alt`、見出し階層、キーボード操作
- SEO：title / description、OGPタグ、構造化

**4. 改善を反映する**
- 改善は `.claude/rules/` のルールに沿って行う（直値禁止・セマンティックタグ等）
- 反映後に再計測し、スコアが改善したか確認する

### つまずいたときの記録
- 計測・改善で問題が起きたら `TROUBLESHOOTING.md` に記録する

### 完了条件（Definition of Done）
- [ ] Lighthouse を PC / モバイルで計測した
- [ ] 目標スコアを下回る項目に対応（または対応方針を記録）した
- [ ] 主要なアクセシビリティ違反が解消されている

### 完了したら次へ
品質が基準を満たしたら `PROGRESS.md` の STEP7 を `[x]` に更新し、`start-orchestrator` で残タスクを表示する。
その後、`deploy-preview` スキル（デプロイ）へ進む。

### 送るメッセージ例
```
このLPにLighthouseを実行し、パフォーマンス・アクセシビリティ・SEOのスコアを計測してください。
パフォーマンス90／アクセシビリティ95を下回る項目があれば、原因と改善案を教えてください。
```
