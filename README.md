## 現在の決定事項

- サイト名：Candy Monster
- サービス表記：新米ママのための、AI × 育児コミュニティ
- 方向性：育児情報を読むだけで終わらせず、AIで自分向けに調整して実践できる場として育てる
- 中心体験：知る → 試す → AIで自分向けにする → 振り返る → 相談・共有する
- 主な対象：0〜6歳の子どもを育てる新米ママ
- 対象年齢の導線：0〜6か月／7〜12か月／1〜2歳／3〜4歳／5〜6歳（横断的な絞り込み軸として扱う）
- 初期カテゴリ：睡眠・生活リズム、ごはん、遊び・知育、ことば・関わり方、家事・時短・両立、AI活用ガイド
- 記事タイプ：悩み解決／試してみる／AI活用／年齢別ガイド／体験談・みんなの声／基礎知識・安心ガイド
- サイトとDiscordの役割分担：サイト＝知る・見つける・試す・記録する／Discord＝相談する・共感する・共有する・つながる
- ファーストビューのメインコピー：AIとみんなの知恵で、育児をもっとラクに、もっと楽しく。
- ファーストビューのサブコピー：初めての育児の「どうしよう？」に、すぐ試せるヒントを。育児情報・AI活用・ママ同士のコミュニティで、あなたらしい子育てを応援します。
- North Star Metric：月間「育児で1つ試せた」ユーザー数
- 安全方針：医療・発達・アレルギー・事故・安全に関わる判断をAIだけに委ねない
